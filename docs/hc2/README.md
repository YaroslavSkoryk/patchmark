# HC-2 architecture records

This directory contains versioned architecture decisions for Patchmark's Human Collaboration HC-2 track.

- `architecture-decisions-v1.md` freezes the Slice 1 production-facing contracts.
- `slice3-crypto-security-review.md` records provider selection, artifact and advisory evidence, vectors, recovery parameters, browser benchmarks, and production-enablement gates.

These records describe contracts and exit gates only. They do not claim that production storage, cryptography, recovery, enrollment, bundle exchange, synchronization, or UI integration exists. Production collaboration remains disabled through the final HC-2 audit.
