# HC-3 architecture records

HC-3 begins disabled, user-mediated collaboration integration while preserving
the completed HC-1/HC-2 local-first foundation.

- `architecture-v1.md` defines self-contained handoff carriers, canonical text,
  fragment links, single-QR eligibility, encrypted bundle-file metadata, and
  the no-cloud direct-connection design.

These records and contracts do not enable production collaboration, add a
network transport, or authorize a user interface. Production collaboration
remains unconditionally disabled and unreachable.
